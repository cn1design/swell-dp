# 【Phase 4 緊急修正】非同期処理によるポップアップブロックの確実な回避

AI連携ボタンをクリックした際、ブラウザ（Chrome等）のポップアップブロッカーが発動し、新しいタブが開かないという致命的なバグが発生しています。

■ 原因
`navigator.clipboard.writeText`（非同期処理）の完了を待ってから `window.open()` を実行しているため、ブラウザが「ユーザーの直接のクリックイベントではない（スパムである）」と判定し、遮断しています。

■ 修正指示（JSロジックの改修）
このブロッカーを確実に回避するため、以下の【空タブ事前確保アプローチ】にJSを書き換えてください。

1. **同期的なタブオープン:** クリックイベントハンドラの直後（`await` などの非同期処理に入る前）に、同期的に `const claudeWin = window.open('about:blank', '_blank');` を実行し、先に新しいタブを確保してください。
2. **非同期コピー:** その直後に `navigator.clipboard.writeText` でプロンプトをコピーしてください。
3. **URLの差し替え:** コピー処理が成功（resolve）したら、確保しておいたタブを `claudeWin.location.href = 'https://claude.ai/new';` に変更してください。
4. **UXの最適化（重要）:** `alert` や `confirm` を出すと、せっかく開いた新しいタブから元の画面にフォーカスが強制的に戻ってしまいUXが最悪になります。`alert` 等のダイアログ表示は一切廃止し、代わりに元の画面のボタンテキストを一時的に「✅ コピー完了！」に変更するなど、UI上の視覚的なフィードバックのみに留めてください。

■ 進行指示
このポップアップブロック回避のロジックを実装し、`npm run build` を実行してください。
完了後、ボタンを押した際にブロッカーに引っかかることなく、スムーズにClaudeの画面が新しいタブで開くことを報告してください。

# 【Phase 4.1 新規要件】AI連携プロンプトに「代替案の提案ロジック」を追加

現在のプロンプトでは、ユーザーの「追加指示（原稿や配置）」が、選択された「ベースブロックコード」のレイアウトや要素数と矛盾する場合、AIが無理にコードを生成して破綻する可能性があります。
より賢く親切なUXを提供するため、プロンプトテンプレートに以下のルール（エスケープルート）を追加してください。

■ 修正指示（JSロジックの改修）
`claude-integration.js` 等に定義されている `claudePromptTemplate` の【絶対厳守ルール】に、以下の内容を追加・マージしてください。

【追加・更新するルール】

- もしユーザーの【追加指示】（原稿の量、要素数、配置の要望など）が、提供されたベースブロックコードの構造にどうしても合致しない場合（例：3列の枠に5つの要素を入れようとしている等）、**絶対にコードの構造を壊したり、無理にテキストを詰め込んだりしないでください。**
- そのような矛盾が発生した場合は、コードを出力する前に、**「なぜ合わないのかの理由」と「SWELLの〇〇ブロックや、別のレイアウト（例：リストブロック、リッチカラム等）を使う方が適しています」というプロフェッショナルな代替案・改善提案**をテキストで提示してください。
- 提案した上で、現在の枠組みの中で「可能な範囲でベストを尽くしたコード」を一緒に出力するか、ユーザーに指示の再考を促してください。

■ 進行指示

AI連携機能において、1点の課題が発生したため至急改修を行ってください。

Claudeの「自動ファイル添付」仕様への対応（プロンプトと案内文の改修）
長文のブロックコードをClaudeにペーストすると、自動的に「テキストファイル」として添付され、チャット入力欄が空になるため、ユーザーがそのまま送信するとClaudeが指示待ち状態になってしまう問題が発生しています。

『【Claudeへの絶対命令】このテキストがファイルとして添付され、かつユーザーのチャットメッセージが空欄だった場合でも、一緒に添付されている原稿ファイル（もしあれば）を読み取り、直ちに以下の【ベースブロックコード】のテキスト書き換え作業を実行してください。ユーザーへの質問は不要です。』

**B. コピー完了時の案内文（alert/confirm等）の変更**

① そのままペースト（長いため自動でファイル添付されます）
② 掲載したい原稿やNotionのテキストもペースト
③ チャット入力欄に「これらをもとに書き換えて」と一言だけ入力して送信！』
