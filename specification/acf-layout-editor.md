仕様：店舗情報 ACF レイアウト変更

対象ファイル: inc/acf-store-fields.php

---

変更①：「基本情報」セクションラベル削除

field_store_section_basic（type: message、label:
基本情報）を丸ごと削除。

// 削除対象
[
'key' => 'field_store_section_basic',
'label' => '基本情報',
'name' => '',
'type' => 'message',
'message' => '',
],

---

変更②：基本情報フィールドを2カラム化

ACF の wrapper['width'] に '50'
を指定すると横並び2カラムになる。
6フィールドを以下の3行ペアで構成：

┌─────────────────┬─────────────────┐
│ 左カラム（50%） │ 右カラム（50%） │
├─────────────────┼─────────────────┤
│ 店舗表示名 │ 電話番号 │
├─────────────────┼─────────────────┤
│ 郵便番号 │ 住所 │
├─────────────────┼─────────────────┤
│ 最寄り駅 │ 定休日 │
└─────────────────┴─────────────────┘

各フィールドに追加するプロパティ：
'wrapper' => [ 'width' => '50' ],
