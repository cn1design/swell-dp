# works ライティングサンプル

> 最終更新：2026-04-14
> 対象パターン：works-01、works-02、works-03

---

## ガイドライン型テキストの方針

works カードの h3 は「お客様の変化・成果を一文に凝縮した見出し」。
ユーザー自身がビジネスに当てはめて書き換えられるよう、切り口の問いを添える。

**文字数は実文字数で厳守**（h3: 10〜18文字）。

---

## カード h3（事例見出し）— 5件

各カードで「変化の切り口」を変えることで、多様な事例に対応できる構成にする。

---

### カード 1｜数値変化型

```
数字で示す変化の見出し
```

| 項目 | 内容 |
|---|---|
| 文字数 | 11文字 |
| 切り口 | 売上・件数・費用などの数値が変化した事例 |
| 問いかけ | 「導入前後で何が・どれくらい変わりましたか？」|

> 書き換え例：`月の問い合わせが3倍になった` / `制作コストが半分に削減` など

---

### カード 2｜課題解消型

```
解消された悩みの見出し
```

| 項目 | 内容 |
|---|---|
| 文字数 | 11文字 |
| 切り口 | 長年抱えていた課題・悩みが解決した事例 |
| 問いかけ | 「導入前に何に困っていて、今はどうなりましたか？」|

> 書き換え例：`集客の悩みが完全に解消された` / `受注漏れがゼロになった` など

---

### カード 3｜時間短縮型

```
時間短縮の成果を一言で
```

| 項目 | 内容 |
|---|---|
| 文字数 | 11文字 |
| 切り口 | 作業時間・工数・納期が短縮された事例 |
| 問いかけ | 「以前は何時間かかっていたものが、今は何時間になりましたか？」|

> 書き換え例：`3日かかった作業が半日に` / `対応時間が週10時間削減` など

---

### カード 4｜感情変化型

```
不安が自信に変わった理由
```

| 項目 | 内容 |
|---|---|
| 文字数 | 12文字 |
| 切り口 | 漠然とした不安・迷いが、確信・自信に変わった事例 |
| 問いかけ | 「導入前に感じていた不安は何でしたか？今の気持ちは？」|

> 書き換え例：`価格設定の迷いがなくなった` / `見込み客への提案に自信がついた` など

---

### カード 5｜継続・安定型

```
継続的な変化を表す見出し
```

| 項目 | 内容 |
|---|---|
| 文字数 | 12文字 |
| 切り口 | スポットではなく、継続的・安定的な成果が出ている事例 |
| 問いかけ | 「一時的な成果ではなく、今も続いている変化は何ですか？」|

> 書き換え例：`半年後も予約が途切れない` / `安定収益が仕組みで回るようになった` など
