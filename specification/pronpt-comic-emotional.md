# 生成指示

テーマから自然な短編4コマを自動で発想し、「少し笑える」「少し切ない」「少し愛おしい」のどれかを含む、余韻のある1ページ漫画にしてください。

構成は以下

1. ページ上部に大きな余白
2. 上部中央に小さく上品なタイトル
3. タイトル下に日本語の短い副題
4. さらにその下に小さな英字の手書き風サブタイトル
5. その下に、縦長1ページの4コマ漫画
6. ページ下部にも余白をしっかり残す
7. 下中央に小さなページ番号のような装飾を入れる

# ビジュアルスタイル

- 全体は、上質なインディーズ漫画作品集や私家版ZINEのような空気
- 線は細く、ラフすぎず、少し揺れのある手描きインク線
- 完璧すぎない線、少し乾いた紙の質感
- 色数は少なめ
- くすみを含む限定パレットで、主役色は2〜4色程度
- 色は「紙の上に軽く置いた」ように見せる
- ベタ塗りしすぎない
- ところどころに軽い色ムラ、かすれ、にじみ感
- おしゃれで静かな誌面デザイン
- 余白を大胆に使う
- コマ枠は細く不均一で、少し手描き感
- 写実すぎず、記号化しすぎず、品のある人物造形
- 表情は繊細、感情表現は小さく
- 大げさなギャグ顔は禁止
- 小物や服装はテーマに合わせて自動選定
- 背景は描き込みすぎず、でもスカスカにしない
- 各コマの構図に変化をつける
- 1コマは寄り、1コマは中距離、1コマは動き、1コマは余韻のある締め
- 全体として、静けさの中に小さな発見があること

# コマ運び

4コマは必ず以下の流れを意識
1コマ目　状況提示、静かな違和感や発見（PC画面を見つめる憂鬱な表情）
2コマ目　少し進展、視線や行動で意味が立ち上がる（画面を遮るように猫が登場）
3コマ目　小さなズレ、勘違い、気づき、可笑しみ（猫が勝手にキーを押してエラー音）
4コマ目　余韻で締める。説明しすぎず、少し心に残る（諦めて猫を撫でる、静かな夜）

# タイポグラフィ

- タイトルは上品なセリフ体または活版風
- 副題は繊細な日本語組み
- 英字は小さな手書き筆記体風
- セリフは手書きの漫画文字風
- セリフは少なめ、短く、間がある
- オノマトペは最小限
- 読ませすぎない
- 絵と余白で読ませる

# 禁止事項

- 露骨な商業アニメ絵
- 派手な背景グラデーション
- 過剰な美少女化、美男子化
- 情報詰め込み
- うるさい装飾
- フォントがデジタルっぽすぎる見た目
- 漫画アプリ広告のような演出
- 大きすぎるセリフ
- ネタ説明
- 4コマ全部が同じ構図

# 出力の最重要条件

「テーマを説明する漫画」ではなく、「テーマから連想される、静かで洒落た短い物語」にすること。絵柄の完成度よりも、ページ全体の空気感、余白、品の良さ、線のニュアンスを優先してください。
