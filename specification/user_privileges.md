# 指示

あなたはプロのWebエンジニアおよびテクニカルディレクターです。
WordPress（テーマ：SWELL）を用いたWebサイト制作において、クライアントへ安全に特定の編集権限を付与するための「権限カスタマイズ要件定義・実装仕様書」を作成してください。

※重要：今回は「実装前の仕様定義」が目的です。具体的なPHPコード（functions.phpへの記述内容など）は出力せず、どのようなロジック・アプローチで実現するか、どのプラグインのどの機能を利用して要件を満たすのかをドキュメントとしてまとめてください。

# 前提条件

- クライアント属性：インフルエンサー（Instagramプロアカウントを運用中）
- プラットフォーム：WordPress
- 使用テーマ：SWELL
- 利用想定プラグイン：
  - Smash Balloon Instagram Feed
  - User Role Editor
  - Adminimize（または同等の管理画面カスタマイズプラグイン）

# 達成したい要件（ビジネス要件）

クライアントに「管理者権限」を渡すことなく、以下の操作のみを許可する専用の権限グループを作成・適用したい。

1. SWELLの「ブログパーツ（swell_part）」のうち、特定（自分が担当に割り当てられたもの）のブログパーツのみ編集できる。
2. InstagramのAPI連携が切れた際、クライアント自身でSmash Balloonの設定画面に入り、再認証手続きができる。
3. クライアントが管理画面にログインした際、上記操作に不要なメニュー（他のプラグイン設定、外観設定、ウィジェット等）はすべて非表示にし、誤操作を防ぐ。

# 仕様化してほしい項目（実装アプローチ）

以下の構成で、要件を満たすための設計書をマークダウン形式で作成してください。

1. 目的と概要
2. システム要件・利用プラグイン一覧
3. 権限ロール設計（新設する権限グループと、付与・剥奪する権限の考え方）
4. 機能別の実装方針（※コードは記述せず、設定のロジックを解説）
   - ブログパーツ（swell_part）への「作成者」サポート追加の考え方
   - Smash Balloonのアクセス権限付与のアプローチ
   - 管理画面のUI最適化（不要メニュー非表示）のアプローチ
5. テスト・検証項目（納品前に確認すべき事項）

※重要：具体的なPHPコードの全体像は出力不要ですが、実装時の解釈ブレを防ぐため、必要なフック名、ケイパビリティ名（edit_postsなど）、およびプラグインの具体的な設定項目名は明記してください。

# 前提条件

- クライアント属性：インフルエンサー（Instagramプロアカウントを運用中）

1. 目的と概要
2. システム要件・利用プラグイン一覧
